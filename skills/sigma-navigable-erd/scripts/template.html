How to read the results
  • Pass-through means the column is a plain reference all the way down. Calculated means at least one layer applies a formula, and that layer's owner is listed.
  • Partial means the chain reaches a data model whose upstream element the API does not expose. The model owner is listed, and "possible upstream" names the models behind it.
  • Tracing matches columns by name through formulas, so treat an owner as the place to start asking, not as proof.
  • Ownership is Sigma object ownership (who owns the workbook or data model). It is not a statement about who is responsible for the business logic.
